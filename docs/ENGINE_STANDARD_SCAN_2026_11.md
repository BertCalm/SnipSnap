# Engine standard scan, 2026-11

A scan of all 82 registered engines against the Luthier registration checklist
(`.claude/skills/luthier/references/snipsnap-conventions.md`, section 3) and the
house probe set (section 5), made on commit `0541715b`. It answers one question:
which engines are not yet fleshed out to the standard the newer engines ship at?

The table at the bottom is regenerated by `python3 scripts/engine_standard_scan.py`.
Every column is a grep, so each one is a **presence** check. A "no" means the file
or keyword was not found, not that the engine is broken. Shared tests
(`PresetsTest`, `PatchesTest`, `DeterminismTest`) cover some engines the per-engine
columns file as missing. Nothing in this document was heard.

## Ledger

- **Verified:** every row of the table, by grep, on the commit above.
- **Measured:** nothing rendered for this scan. The ROOT stepper work in the same
  change has its own measurements in `SynthRootTest`.
- **Proposed:** the tiers and the order below.
- **Heard:** nothing. Only the owner hears.

## Registered but not on the phone

These have a Patch and render through the CLI, but have no `EngineCatalog` entry,
so the SYNTH picker never shows them.

- **Built and rostered, picker missing:** BORE, ARCO, SCOUR, KEEL. Each has presets,
  a kit and an audition. Adding them to the picker is the cheapest win in this scan.
  It needs an SDK session ("a picker button guessed blind is worse than one left").
- **Rosterless by decision:** SNAP, TERRA, SILK, GYRE, MAGNET (`PatchTypes.ROSTERLESS`).
- **Prototypes awaiting a listening verdict:** EROSION, CAIRN, WICK, FERRY
  (`PatchTypes.PROTOTYPES`). NACRE is also a prototype but is on the picker.

## HOLD with no seam test in the engine's own tests

The checklist asks every HOLD to prove a real loop (`Keys.seamError` under
`Keys.MAX_SEAM_ERROR`) or to refuse its top step with a test that says so. These
engines have a HOLD macro and no seam keyword in their own test files:

LIBRATION, TREFOIL, FERRY, THUMP, BORE, GYRE, AEROSTAT, CISTERN, THAW, SCOUR,
SUTURE, OSPREY, FLOCK, OBBLIGATO, ORPHICA, CHAMBER, NACRE, KEEL, CAUSTIC.

Several are known refusals or finite-length HOLDs (CAUSTIC reserves HOLD, NACRE
refuses it, OBBLIGATO's HOLD extends a finite note, THUMP's is a decay). The
work is to read each and either name the refusal test or add the seam test.

## Other probe gaps worth a look

Counted by keyword in each engine's own tests (`--gaps` lists them all):

- **Determinism canary:** TIDE, SNAP and GYRE have none in their own tests and none
  in `DeterminismTest`.
- **Root pitch:** SKIN, TINES, PLUCK, TONEWHEEL, VELVET, SNAP and EROSION have no
  pitch-detect assertion. PLUCK and TINES are tonal and should have one.
- **Non-finite macro fallback:** SNAP, SILK and AEROSTAT.
- **"Every macro changes the sound"** is the weakest probe across the roster (44
  engines without the phrase). Some cover it under other wording, so this list is
  a reading list, not a defect list.

## Keygroup reach

Only 22 engines reach MAKE INSTRUMENT through a `Keys.xxxPad` or a `:shell`
PadMaker. The inventory's "thin by slot" finding stands: many HOLD engines never
export as instruments.

## ROOT and OCT steppers (done in this change)

The SYNTH picker shows 69 engines. 65 of them now get the ROOT / OCT row that
STOOP and ORPHICA had, TINES on its KALIMBA voice only. `SynthRoot` also gives a
root to the engines off the picker, so the row is there when one is added.

Engines with no row, and why:

- **Drums:** THUMP, SKIN, ONSET, TERRA. A pitched stepper on a kick names a note
  nobody plays it at.
- **VOX:** formants and beatbox, no single root.
- **SILK:** TUNE walks scale degrees, not semitones.
- **EROSION, and TINES' bells and blocks:** TUNE sweeps a continuous frequency, so
  a note name would be wrong.
