# MURMUR kept sources in the product

M1 adds three PLUCK presets without replacing any of the original 42 recipes: HOLLOW WIRE NOTE, HOLLOW WIRE HOLD and STEADY ROOT C2. The old two MURMUR starters remain unchanged. All three new recipes are one PLUCK voice; prior KEY/CHOIR choices are retained and BASS/LEAD/METAL listening selections remain open.

`MurmurKeptSources` stores immutable original native and heard-recipe text, their byte hashes, the unique editable alias, the supported native root range and exact reference gain/WAV/presentation identities. Every Patch read decodes a new deep copy. The saved native profile remains opt-in model 4; legacy render models and default construction stay unchanged. Factory Patch/PadRecipe playback uses the existing house normalization and velocity response. The retained raw-reference gain is provenance, not a new PadRecipe effect or an assertion that a factory render equals the heard recording. No raw-gain source contract or new renderer model is introduced.

MURMUR KEPT is a separate 16-pad starter: seven arranged KEY motion-.5 notes (48,51,53,55,58,60,63), four authored KEY MOTION settings, the three kept PLUCK anchors and two authored lower-air CHOIR settings. Source and derived recipes have separate identities. Held sources on one-shot pads receive an explicit saved 8-ms terminal delivery fade; finite sources retain their finite tails. This ending is not a natural-release claim. Each pad carries its authored derived MIDI root stamp and source metadata. The three kept-pluck pads also carry the complete selected-source record in kit.json, so their original native/heard profile does not depend on an auxiliary file being retained by an external format. The starter writes `murmur-kept-source-bank.json` before kit.json makes the folder visible.

The real app factory path sees all three unique aliases. Complete config/model/body/root/velocity and the latest macro edit are retained through factory/draft/YOURS restoration, same-frame SAVE and navigation. Revised MURMUR bodies are explicitly refused by the generic forced-HOLD/full-keyboard instrument maker, including direct held/zone calls. Models 1–3 retain their previous eligibility. Dedicated bounded finite/held makers are M2: finite STEADY ROOT MIDI 36–54, finite/held HOLLOW WIRE 36–96, explicit source/cell provenance, no forced finite HOLD, no out-of-range chord clamping and no implicit 0–127 expansion.
