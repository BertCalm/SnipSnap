# UAT pass, November 2026

Follow-up to [`UAT_2026_09.md`](UAT_2026_09.md). Two layers, both run on 2026-11-02:

1. **JVM sim**: `UatSimTest` driving `:shell`'s real models (`./gradlew :shell:test --tests '*UatSimTest*'`).
   Transcript: `<java.io.tmpdir>/uat-transcript.txt`. Counts, wording and verdicts are measurements.
2. **Emulator**: debug APK built from local HEAD (`6d622762f`, 49 commits behind origin at the time),
   `snipsnap_pixel` AVD, 1080x2400, driven with `adb` taps, screenshots and `uiautomator dump`.

Both ran on a 8 GB Mac that was already swapping; the AVD was booted with
`-memory 2048 -no-snapshot -no-audio -no-boot-anim -gpu swiftshader_indirect`, one Gradle build at a time.

## Pass 2 (emulator, fresh install each boot)

The AVD's data partition is a temp disk, so every boot is a clean install: good for first-run checks.
Mic and notification permissions were granted with `adb pm grant`, so the system dialogs were not seen.

## Triage after reading the source (2026-11-03)

Of the eight screen-level findings first proposed as fixes, six turned out to be documented design choices or
non-defects (E1-DEST, E1-LINE, E1-CLIP, E2-BANKB, E2-PORTRAIT, and the J2-DEADEND sim finding). What remains real:

- **E2-STALE** (TAPE empty state says "TAP LISTEN - MIC BELOW" while armed): needs a copy decision in the app's voice,
  an armed-aware `EmptyDeck`, and an `androidTest`. Not done here.
- **E2-OVERLAY**, **E2-CHOOSER**, **E1-CTRL**, **E1-PICK**, **E1-WRAP**, **E1-EMPTY**, **E2-RAW**: judgement calls for the owner.

**Lesson for the sim:** a UAT finding should be checked against the code's own comments before it is filed; this repo
records its reasoning next to the strings.
