# UAT pass, November 2026

Follow-up to [`UAT_2026_09.md`](UAT_2026_09.md). Two layers, both run on 2026-11-02:

1. **JVM sim**: `UatSimTest` driving `:shell`'s real models (`./gradlew :shell:test --tests '*UatSimTest*'`).
   Transcript: `<java.io.tmpdir>/uat-transcript.txt`. Counts, wording and verdicts are measurements.
2. **Emulator**: debug APK built from local HEAD (`6d622762f`, 49 commits behind origin at the time),
   `snipsnap_pixel` AVD, 1080x2400, driven with `adb` taps, screenshots and `uiautomator dump`.

Both ran on a 8 GB Mac that was already swapping; the AVD was booted with
`-memory 2048 -no-snapshot -no-audio -no-boot-anim -gpu swiftshader_indirect`, one Gradle build at a time.

## Rulings (Josh, 3 to 6 November)

Six of the fourteen findings above turned out to be documented design, not defects: the CARD caption, the NEW TAPE line, the bench scroll, bank B being the first empty bank, the portrait lock and the J2 dead end. The repo records its reasoning beside the code, so read that before filing a finding.

| Finding | Ruling | State |
|---|---|---|
| E2-STALE | The armed TAPE line says what SNIP keeps: "TAPE ROLLING. SNIP KEEPS WHAT IT'S HEARD, UP TO 60s." | Merged, #876 |
| E2-RAW | Explain RAW in HELP, in the PADS section | Merged, #876 |
| E2-OVERLAY | Say why before the jump to "Display over other apps", as a line plus an ALLOW ▸ door, not an instant jump | Queued |
| E2-CHOOSER | Remember the last MIC / APP AUDIO choice, change it in SETUP, and have the dock name the source | Built: `CaptureSource`, the dock chip, SETUP's LISTEN FROM group |
| E1-CTRL | Add a one-word label above STRIKE / LEFT / STAY / VOL and keep the button words | Queued |
| E1-WRAP | Pad labels shrink to one line, in their own small composable | Queued |
| E1-PICK | Group the 67 starters under headings; Josh vetoes the heading list first | Heading list owed |
| E1-EMPTY | Rethink the empty shelf: a proposal, not a build | Proposal owed |
| BEAT-LANES (5 Nov) | The step rows read KICK, SNARE… whatever the kit; name each row after the pad it plays | Queued, with E1-WRAP |

### The two regroup proposals

- **Pad editor and SYNTH screen** (5 Nov), ruled B A A A A:
  - A short pad editor, with EFFECTS and VARIATIONS as their own screens.
  - One LAYERS group. This departs from the clarity spec's §7.7.
  - One header UNDO that names what it undoes, if a build check shows it can always reach the latest change.
  - SYNTH reordered, with headings only and SEND TO PAD beside AUDITION.
  - Built now, SYNTH first.
- **The other screens** (6 Nov), ruled A A A A A:
  - LOOP gets a visible CLEAR with UNDO. Holding a block used to clear and save the track with no undo.
  - One project tempo, set from BEAT.
  - SONG's plan is kept in the project. This is a new feature.
  - DECK's KEEP, which writes nothing, becomes USE THIS PART ▸.
  - Build order: the tier-1 fixes, then the two sound pages, then the clarity spec's PR 6 (a visible twin for every hold) with LOOP, then tier 3 one place at a time, then spec PR 4 with the ▸/▾ rule.
- **Tier-1 correction:** the proposal said the BIN door's count leaves out forgotten rooms. It doesn't need to: binned rooms are listed, restored and emptied on the shelf itself, and the BIN bench holds kits and snips only. Not changed.
