## Intent and decisions to preserve

The starting idea was the [Aquatic Master FX concept](https://github.com/BertCalm/XO_OX-XOmnibus/blob/main/Docs/concepts/aquatic_master_fx_concept.md),
adapted to SnipSnap alongside its separate
[pedal-board plan](../superpowers/specs/2026-10-04-pedal-board-design.md).
The [integration design](../superpowers/specs/2026-10-18-aquarium-integration-design.md)
records upstream provenance, corrections, licensing and the listening decision.

- Josh accepted the six-effect audition and both PAD/performance placements on
  October 18, 2026. That is the accepted sonic baseline, not phone/MPC acceptance.
- Keep the order **Fathom → Drift → Tide → Reef → Surface → Biolume** and all 52
  canonical physical controls. Depth pairs Fathom/Surface, Motion pairs
  Drift/Tide, and Color pairs Reef/Biolume without changing signal order.
- Reuse the accepted native core. Preserve model/version behavior, deterministic
  seed handling, presets, provenance and upstream license. A material sonic
  change requires its own comparison and listening evidence.
- New routes start dry. SURFACE, ORBIT and SPLIT explicitly opt into the saved
  KIT PERFORMANCE sound; each owns independent effect history.
- PAD effects bake into portable WAVs. A live SnipSnap bus is not an MPC insert.
  Baked audio can receive KIT FX again when played through an enabled bus.
- PEDALS remains a separate system and roadmap. Aquarium does not imply that
  every proposed pedal stage has shipped or change the approved treatment row.

## SPLIT details the next developer needs

**FX → USE KIT FX** saves only opt-in and tail in version-1 `split.json`. KIT owns
the sound, seed, bypass, output gain and tempo. One native bus follows the stem
sum and existing +/-1 input clamp. The FX dialog supplies RESET TAIL and status.

PRINT freezes the desk and route. An unused route keeps the exact legacy
`Layers.render` result, including floating overs. A patched route renders a
fresh stereo pass at the source rate, then exact zero input for a chosen
0..30-second tail (default 3). Bypass/all-zero mixes add no tail. Wet mute still
clocks its tail and must be silent from frame zero.

The configured native factory **publishes selected settings before preparation**.
Reversing that order leaks a dry attack into a saved wet mute. Keep this ordering
and its test. ORBIT's adapter deliberately retains its earlier startup behavior.

PRINT preflights both the three-minute shelf cap including tail and the native
output-frame bound. Wet output uses the accepted fixed gain and stereo-linked
0.99 sample-peak protection; it adds no automatic end fade. Subsequent resampling
can change peaks. SNIPS/PAD retain stereo, while TAPE's editor still reads mono.
A finite tail can cut decay or create a loop seam. A fresh source-rate print can
differ from actual-rate live resampling and accumulated loop history.

Kit switching disposes the outgoing player and cancels split/render delivery.
Already-accepted sidecar saves survive navigation, target their original kit
under `KitWrites.mutex`, and refuse a removed directory. Focus/background release
stops playback; foreground waits for fresh PLAY. SPLIT pumps retained controls
and stops, and PLAY can retry a missing stream.

   This is the recommended next integration direction, not implemented scope.

```sh

./gradlew --no-daemon test

# JVM suite when an Android SDK is selected
./gradlew --no-daemon test -x :app:test

# Android compiler/build and device suite, with SDK/device available
./gradlew --no-daemon :app:assembleDebug :app:compileDebugAndroidTestKotlin
./gradlew --no-daemon :app:connectedDebugAndroidTest

# Native harness; supply SNIPSNAP_OBOE_INCLUDE to CMake if using local headers
python3 scripts/check_native_sources.py
cmake -S app/src/main/cpp/test -B build/native-tests
cmake --build build/native-tests
ctest --test-dir build/native-tests --output-on-failure
```
