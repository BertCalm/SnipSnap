## What exists

The gesture is charge → irregular discharge → delayed collapse → thinning dust.
An 8 kHz finite scheduler drives smooth bipolar spark kernels and delayed
collapse chirps at 4× the 44.1 kHz mono output rate. ARC emphasizes fine sparks,
CRATER emphasizes collapse, and SCAR spends reserved energy after a recovery gap.
The reservoir is a bounded energy-budget analogy, not a plasma simulation.

Six macros are TUNE, VOLTAGE, FEED, FLUID, SLAG and GRAIN. GRAIN collects larger
charge packets and extends recovery. Its zero default preserves the old
arithmetic exactly; saved sounds retain their output. `MODEL_VERSION` remains
1. TUNE is relative percussion tuning, not a promised MIDI root. HOLD is absent
and saved patches reject it. The finite tail is not a seamless loop.

Main source directory: `synth/src/main/kotlin/com/snipsnap/synth/`.

## Reproduction

From the repository root with a working JDK/dependencies:

```sh
./gradlew --no-daemon :synth:test --tests 'com.snipsnap.synth.ErosionTest' --tests 'com.snipsnap.synth.ErosionBankTest'
./gradlew --no-daemon :synth:generateErosionBank
./gradlew --no-daemon test
```

The first command covers 11 core/bank methods, not all 83 focused checks. Add
the EROSION canary in `DeterminismTest`, `PatchesTest`, shell `ConventionTest`
and next-round integration tests as appropriate.

Generation defaults to `testkit/erosion-contrast-bank/`; use
`-PerosionBankOutput=/absolute/new/output` to preserve an existing artifact.
Generation alone does not recreate the separately attached historical review,
source package or validation evidence. To attach historical comparisons, run
`python3 scripts/erosion-contrast-review.py NEW_OUTPUT OLD_PLAYING_ROUND` with
the downloaded/extracted frozen previous round.

Without an SDK, run full JVM tests without `-x :app:test`. With app included,
follow current Steward/CI instructions and compile Android separately. No C++
audio changed in EROSION or this documentation handoff.

## Why it is built this way

- Eight roles preserve the contrast Josh accepted after the broader bank overlapped.
- Integration turns the audition into a usable instrument while its sound stays fixed.
- Touch/export checks matter because sampler volume and engine contact character differ.
- HOLD changes the energy supply and ending, so it deserves its own design and listen.
