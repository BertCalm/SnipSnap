## What is built

WICK is an offline pitched instrument: one complex source feeds three recovering
low-pass gates, whose releases schedule later excitation. Its articulation model
includes depletion and recovery; it is not a physical energy-conservation model.

- Six voices: **PLUCK, WOOD, BREATH, BUBBLE, FLICKER and RATTLE**.
- Six normalized controls: **SPARK, FEED, CASCADE, TIMBRE, RECOVERY and HOLD**.
  MIDI ROOT 24–84 and native VELOCITY are stored separately.
- A shared factory bank of **36 editable recipes**, six per voice, used by the
  phone picker, CLI and preset registry.
- RATTLE defaults to **Warm wire**, with **Hollow reed** and **Rubbed glass** as
  saved body choices. Older recipes without a body field retain `CURRENT`,
  displayed as Previous body when active. New recipes save the body explicitly.
- Typed patches retain body, note, velocity and controls through edits,
  navigation, SAVE/YOURS recall and SEND TO PAD. Authored roots survive pad
  creation and SPREAD; preset roster exports preserve the complete patch JSON.
- The dry sixteen-pad starter appears in **FRESH TAPE → MOVING AND STRANGE → WICK**.
  It includes all three RATTLE bodies at C4 and three held pads. The starter is
  a selection from the bank, rather than a container for all 36 recipes.
- The audition offers native/matched audio, controls and register probes,
  causal diagnostics, musical phrases, held clips, individual recipe downloads,
  the 36-patch bank ZIP, implementation source and the playable MPC kit.

The owner accepted the six working voice directions and the three RATTLE bodies.
The earlier chaotic/poppy BUBBLE and repeated-hit RATTLE responses remain
historical comparisons. The original 27 recipes, 1,303 existing WAVs and MPC kit
ZIP were preserved during the final integration. The nine added recipes still
await a separate listening verdict.

**HOLD exports sustain material only.** An ordinary exported kit pad plays its
buffer once. Browser Repeat loops it; an attack followed by continuous sustain
requires a separate instrument/looping adapter.

## Reproduce and measure

Use JDK 17 for the Android build, SDK 35, NDK `27.2.12479018` and CMake `3.22.1`.
Configure your own SDK path through `local.properties` or `ANDROID_HOME`.
This cloud workspace did install a working SDK and build the APK; older
generic notes about cloud SDK unavailability do not describe that run.
Run Gradle builds sequentially.

```sh
# Generate dry audio, the body study and both MPC exports.
./gradlew --no-daemon :synth:generateWickAudition \
  :synth:generateWickSourceStudy :synth:generateWickKit

# Build a current APK and compile its device tests.
./gradlew --no-daemon :app:assembleDebug :app:assembleDebugAndroidTest

# WICK correctness on one connected device.
./gradlew --no-daemon :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.snipsnap.app.ui.WickSynthScreenTest

# Production phone benchmark: all six voices and three bodies, finite/held.
./gradlew --no-daemon :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.snipsnap.app.WickRenderBenchmark \
  -Pandroid.testInstrumentationRunnerArguments.wickProfile=true \
  -Pandroid.testInstrumentationRunnerArguments.wickRuns=3

# Portable JVM timing, with a different warm-up protocol from the hoist study.
./gradlew --no-daemon :synth:benchmarkWick \
  -PwickWarmups=1 -PwickRepetitions=7 \
  -PwickSourceRevision="$(git rev-parse HEAD)"
```

The phone benchmark writes `wick-render-profile.json` to the target app's cache
and instrumentation output. It excludes assertions, playback and disk IO from
timing. The JVM profile defaults to `testkit/wick-audition/render-profile.json`.
Neither benchmark infers a latency pass from a successful execution.

For application changes follow the current workflows and Steward's full gates:
`./gradlew --no-daemon test` without an SDK, or
`./gradlew --no-daemon test -x :app:test` with one. Run the native CMake harness
when changing C++ or its build files. This handoff changes documentation only;
application tests were not rerun for the handoff commit.
