# Finite MURMUR RR owned loading

This slice connects the separately admitted finite STEADY ROOT C2 RR shelf bank to a dedicated native player owner. It adds no sound, voices, renders or UI exposure. The 84 cells remain seven root zones × three authored touches × four takes of one selected PLUCK setting. Held/HOLLOW's 252 cells remain excluded. Existing ordinary InstrumentPlayer, shelf sidecars and saved public package validators retain their existing paths.

`MurmurRoundRobinShelf.streamPcm` verifies the saved handle's exact admission seal, bounded inventory and canonical finite source. The new validation path reads each input through a size/hash-pinned bounded reader. Each WAV is decoded from the same byte snapshot used for PCM24/44100/mono header, frame count, raw hash and sampler-sheet checks. After full validation, a second pass sends one decoded cell at a time to its synchronous consumer, checking exact decoded Float hash. A final complete identity/inventory recheck must succeed before the stream returns. A consumer failure, cancellation, altered cell, changed admission or final mutation prevents successful publication. Consumers must not retain cell arrays.

The 128 MiB limit is a **PCM and transfer working budget**, not total process RSS. Preflight precedes decoding: resident old PCM + pessimistic 4 × total raw WAV bytes for new PCM + 16 × largest raw WAV for raw/decode/hash/sampler/JNI copies + 32 MiB metadata reserve. Metadata input is separately capped at 4 MiB aggregate and 512 KiB per file. The actual retained bank has 2,176,013 bytes of metadata across 17 files; the largest is 255,175 bytes. Its 84 WAVs total 14,454,552 bytes (largest 172,078 bytes). With an old 19,262,880 byte bank resident, conservative predecode working budget is 113,388,768 bytes, below 128 MiB. Once descriptors are validated, the exact second budget uses old decoded PCM + new decoded PCM + 16 × largest allowed cell WAV + 32 MiB. Final validation includes both old and newly loaded native PCM as resident. The retained bank's decoded total is 19,262,880 bytes. JNI moves its copied vector into the native bank; it does not retain another full-grid copy. Dead JVM buffers may remain until GC; the budget bounds live working data, not GC heap commitment. Native engine objects, Oboe streams and Aquarium startup allocations are additional unqualified device overhead; this gate gives no Android RSS credit.

`MurmurRoundRobinOwnedPlayer.open` stages a fresh native handle and fresh admission controller for every bank. It records actual native sample indices and validates the entire 84 cell mapping before commit/start. Only after transfer, commit, start and cancellation checks succeed does it swap owners. Failure destroys only the staged handle and preserves the prior loaded bank. Start may legitimately fail when an old exclusive audio stream remains open; the old player is preserved and no replacement success is reported. The operation holds the owner monitor through blocking IO: other control calls wait, and future UI adoption must provide a busy/cancellation flow rather than promise interactive keys during replacement. Existing native playback can continue while the loader holds the monitor.

The unchanged controller owns whole-chord admission, shared zone cursors, global eight outstanding voices including release tails, and pending stop debt. The owner schedules 16 ms retries when the native stop queue refuses a release. Retry tickets and owner identity invalidate stale callbacks after replacement or close. Scheduler rejection preserves visible debt for the next poll/control call. Route restart retains the same controller and monotonic IDs, invokes native start, then drains the endings from the prior stream before new attacks. Failed restart destroys that owner and requires explicit fresh reload. Close is idempotent; reentrant close during cancellation cannot resurrect the staged bank. Reentrant open/control during loading is refused.

The additive RR JNI prepare/add/commit/start boundaries contain C++ allocation exceptions, preserve pending Java exceptions and release partially prepared owners/failed streams. Existing native entry points are unchanged. Deterministic fake-engine allocation-failure tests are separate from actual PadEngine/JNI loading and ended-ID isolation cases. A retained 84 cell host smoke uses the real shelf/owner with a synchronous fake native copy backend; it proves raw/decoded hashes and every root/touch/take-to-native-index mapping, not Android playback.
