**Files:**

- Test: append to `audio/src/test/kotlin/com/snipsnap/audio/GrainFieldTest.kt`

**Interfaces:**
- Produces:
  ```kotlin
  class Projector internal constructor(
      internal val means: FloatArray,        // 9
      internal val axis1: FloatArray,        // 9, unit eigenvector
      internal val axis2: FloatArray,        // 9
      internal val min1: Float, internal val max1: Float,
      internal val min2: Float, internal val max2: Float,
      internal val degenerate1: Boolean, internal val degenerate2: Boolean,
  ) {
      /** Projects a Similar.vector-style 9-dim vector into the map's 0..1 space. */
      fun project(vector: FloatArray): Pair<Float, Float>
  }
  data class GrainMap(
      val grains: List<Grain>,
      val grainFrames: Int = GRAIN_FRAMES,
      val projector: Projector? = null,   // null only for hand-built maps in old tests
  )
  ```
- `analyze` populates `projector` from the SAME means/eigenvectors/min-max it used for the grains. `project`: mean-center → dot with each axis → min-max normalize with the same min/max → clamp 0..1; a degenerate axis returns 0.5 for that coordinate (the index-spread fallback can't apply to new audio).

```kotlin
@Test
fun `projector puts a grain's own vector back on its map position`() {
    val snip = toneThenNoise()
    val map = GrainField.analyze(snip)!!
    val projector = map.projector
    assertNotNull(projector)
    // Re-extract the first grain's vector by hand and project it: must land
    // (within clamp/rounding) on that grain's stored coordinates.
    val g = map.grains.first()
    val mono = Cleanup.toMono(snip)
    val window = Snip(mono.samples.copyOfRange(g.startFrame, g.startFrame + GrainField.GRAIN_FRAMES), 1, 44_100)
    val v = Similar.vector(FeatureExtractor.extract(window))
    val (x, y) = projector.project(v)
    assertTrue(kotlin.math.abs(x - g.x) < 1e-3f && kotlin.math.abs(y - g.y) < 1e-3f,
        "round-trip drifted: ($x,$y) vs (${g.x},${g.y})")
}

@Test
fun `foreign audio projects to the matching territory`() {
    val map = GrainField.analyze(toneThenNoise())!!
    val projector = map.projector!!
    // A FRESH tone (different phase/freq-ish but tonal) must land nearer the tone
    // cluster's centroid than the noise cluster's.
    val n = GrainField.GRAIN_FRAMES
    val tone = FloatArray(n) { (0.6 * kotlin.math.sin(2.0 * Math.PI * 233.0 * it / 44_100.0)).toFloat() }
    val v = Similar.vector(FeatureExtractor.extract(Snip(tone, 1, 44_100)))
    val (x, y) = projector.project(v)
    val half = 44_100
    fun centroid(g: List<GrainField.Grain>) = Pair(g.map { it.x }.average(), g.map { it.y }.average())
    val ct = centroid(map.grains.filter { it.startFrame + GrainField.GRAIN_FRAMES <= half })
    val cn = centroid(map.grains.filter { it.startFrame >= half })
    val dTone = kotlin.math.hypot(x - ct.first, y - ct.second)
    val dNoise = kotlin.math.hypot(x - cn.first, y - cn.second)
    assertTrue(dTone < dNoise, "a foreign tone landed in noise territory (dTone=$dTone dNoise=$dNoise)")
}

@Test
fun `projection clamps out-of-range audio into the field`() {
    val map = GrainField.analyze(toneThenNoise())!!
    val loudClick = FloatArray(GrainField.GRAIN_FRAMES).also { it[0] = 1f }
    val v = Similar.vector(FeatureExtractor.extract(Snip(loudClick, 1, 44_100)))
    val (x, y) = map.projector!!.project(v)
    assertTrue(x in 0f..1f && y in 0f..1f)
}
```

## Task 2: DUET mode on the grain field (`:app`)

**Files:**
- Modify: `app/src/main/kotlin/com/snipsnap/app/ui/GrainFieldScreen.kt`
- Modify: `app/src/main/kotlin/com/snipsnap/app/App.kt` (thread `onRequestArm` into the screen)

**Interfaces:**
- Consumes: `map.projector.project(v)`; `MicSessionService.snapshotTail(frames)`, `.armed`/`.level` StateFlows, `SAMPLE_RATE`; App's `requestArm` (the same param plumbing PadCaptureScreen uses); `FeatureExtractor.extract` + `Similar.vector`.
- Produces: a DUET toggle chip on the field's header.

**Behavior (locked):**
- Header gains a `DUET` chip (engaged-style visual like the IN/OUT lit buttons). Toggling on when the mic is NOT armed shows a small `START MIC` affordance instead of silently failing (reuses `onRequestArm`; once armed the loop starts).
- While DUET on AND armed: a `LaunchedEffect` loop every 100ms — `snapshotTail(GrainField.GRAIN_FRAMES)`; if null skip. Read `MicSessionService.level.value`: below `0.02f` → `voice.gate(false)` (answers sound, not room hiss) and skip analysis; above → on `Dispatchers.Default` extract features → `Similar.vector` → `projector.project` → smooth the target (`target = lerp(prev, new, 0.5f)` to stop cursor teleporting) → `voice.setTarget` → `voice.gate(true)`.
- Finger override: while a pointer is down, the manual path owns target+gate exactly as today (the DUET loop checks a `touching` flag and stands down); on lift with DUET on, the auto loop resumes.
- The auto cursor renders like the touch cursor (accent ring, maybe hollow to distinguish) — position read inside the draw lambda.
- DUET off → loop stops, `gate(false)` unless a finger is down.
- Hint line while DUET on: `THE MIC PLAYS THE FIELD. HEADPHONES RECOMMENDED.` (speaker→mic feedback is real; level-gating limits but does not remove it — KDoc-note it).
- `map.projector == null` (shouldn't happen for analyze-produced maps) → DUET chip hidden.
