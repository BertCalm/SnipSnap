**Goal:** A SMEAR treatment: the tonal body of a sound stretches and bleeds while its transient attacks stay crisp at their original positions — HPSS + phase-locked stretch, composed the way the repo's own failed experiment says NOT to do it, inverted correctly.

**Architecture:** New pure DSP `Smear.process(snip, amount)` in `:audio` (JVM, TDD): `Separate.hpss` splits → percussive half passes through UNTOUCHED (the load-bearing design rule — `Retime`'s KDoc records that stretching both halves smeared a kick attack 33ms→51ms, and that failure must not be recreated) → harmonic half is `Pghi.stretch`ed by an amount-driven factor, truncated to the original length with an end fade → remixed. UI: SMEAR joins the PAD SHEET treatment picker as a fourth segment, routed through `KitBuilderModel.replaceAudio(slot, recipe) { Smear.process(...) }` (the `Mutate.morph` precedent), not through `eraPad`.

**Tech Stack:** Kotlin; existing `Separate` (HPSS), `Pghi.stretch`, `Cleanup` utilities; `kotlin.test` + JUnit5 in `:audio`; Compose in `:app`.

## Task 1: `Smear.process` — pure DSP + tests

**Files:**
- Create: `audio/src/main/kotlin/com/snipsnap/audio/Smear.kt`
- Test: `audio/src/test/kotlin/com/snipsnap/audio/SmearTest.kt`

**Interfaces:**
- Consumes: `Separate.hpss(snip): Split` (`Split(harmonic: Snip, percussive: Snip)`, masks sum to 1 so parts reconstruct the input); `Pghi.stretch(source, factor, seed): Snip` (factor > 1 = longer, mono); `Cleanup.toMono`, `Cleanup.applyFades` (or manual short fade); `Snip`.
- Produces:
  ```kotlin
  object Smear {
      /** amount 0..1 → harmonic-bed stretch factor 1.0..2.5; 0 = untouched. */
      fun process(snip: Snip, amount: Float): Snip
  }
  ```

**The algorithm (design locked — deviations need a reported reason):**
1. `amount <= 0f` → return the input unchanged (identity fast-path).
2. Fold to mono (`Cleanup.toMono`) — document why (Pghi mono contract).
3. `Separate.hpss(mono)` → harmonic + percussive.
4. **Percussive: pass through untouched.** Never stretched, never shifted — this is the anti-Retime-failure rule; put a comment citing Retime's KDoc experiment.
5. Harmonic: `Pghi.stretch(harmonic, factor = 1f + 1.5f * amount.coerceIn(0f, 1f))` → take the FIRST `mono.frameCount` frames (stretch > 1 so it's longer; if shorter for any edge reason, zero-pad) → short fade-out over the final ~5ms to kill the truncation edge.
6. Mix: `out[i] = percussive[i] + smearedHarmonic[i]`. Because hpss masks sum to 1, at factor→1 this approaches the input. If the mixed peak exceeds 1f, scale the whole output down by `1f/peak` (down only — never boost).
7. Return `Snip(out, 1, snip.sampleRate)`.

```kotlin
package com.snipsnap.audio

import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNotNull
import kotlin.test.assertSame
import kotlin.test.assertTrue

class SmearTest {
    // A kick-like thump at frame 0 plus a decaying 220Hz tone from 0..0.4s, 1s total @44.1k.
    private fun fixture(): Snip {
        val n = 44_100
        val out = FloatArray(n)
        // thump: 40ms decaying 60Hz burst, sharp attack
        for (i in 0 until 1_764) {
            val env = 1f - i / 1_764f
            out[i] += (0.9f * env * env * kotlin.math.sin(2.0 * Math.PI * 60.0 * i / 44_100.0)).toFloat()
        }
        // tone: 220Hz, decays to silence by 0.4s
        for (i in 0 until 17_640) {
            val env = 1f - i / 17_640f
            out[i] += (0.5f * env * kotlin.math.sin(2.0 * Math.PI * 220.0 * i / 44_100.0)).toFloat()
        }
        return Snip(out, 1, 44_100)
    }

    private fun bandEnergy(snip: Snip, hz: Double, fromFrame: Int, toFrame: Int): Float {
        // Simple goertzel-style probe over the window (reuse CaptureDoctor.goertzel if public; else inline)
        var re = 0.0; var im = 0.0
        for (i in fromFrame until minOf(toFrame, snip.frameCount)) {
            val phase = 2.0 * Math.PI * hz * i / snip.sampleRate
            re += snip.samples[i] * kotlin.math.cos(phase)
            im += snip.samples[i] * kotlin.math.sin(phase)
        }
        return kotlin.math.sqrt(re * re + im * im).toFloat()
    }

    @Test
    fun `amount zero is identity`() {
        val s = fixture()
        assertSame(s, Smear.process(s, 0f))
    }

    @Test
    fun `length is preserved`() {
        val s = fixture()
        assertEquals(s.frameCount, Smear.process(s, 0.6f).frameCount)
        assertEquals(s.frameCount, Smear.process(s, 1f).frameCount)
    }

    @Test
    fun `the attack stays crisp and in place`() {
        val s = fixture()
        val smeared = Smear.process(s, 1f)
        val dryOnset = Transients.detect(s).firstOrNull()
        val wetOnset = Transients.detect(smeared).firstOrNull()
        assertNotNull(wetOnset, "smeared output must still have a detectable attack")
        assertNotNull(dryOnset)
        assertTrue(
            kotlin.math.abs(wetOnset.frame - dryOnset.frame) <= 1_024,
            "attack moved: dry ${dryOnset.frame} vs wet ${wetOnset.frame}",
        )
    }

    @Test
    fun `the tonal body bleeds later than the dry tone`() {
        val s = fixture()
        val smeared = Smear.process(s, 1f)
        // Dry tone is over by 0.4s; probe 0.45s..0.8s where only the smeared bed should live.
        val lateDry = bandEnergy(s, 220.0, 19_845, 35_280)
        val lateWet = bandEnergy(smeared, 220.0, 19_845, 35_280)
        assertTrue(lateWet > lateDry * 2f, "expected the smeared bed to bleed past the dry decay (dry=$lateDry wet=$lateWet)")
    }
}
```
