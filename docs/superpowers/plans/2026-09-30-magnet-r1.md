# MAGNET R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the MAGNET electric-guitar-string engine (voices JANGLE and CHUG; macros TUNE, MUTE, PICK, BLEND) on the string toolkit and R0's pickup comb, registered with the patch system, with its kit and an audition generator, ready for the owner's R1 audition gate. No presets (they are authored by ear after the gate), no phone (R1.1).

**Architecture:** `Magnet.kt` renders a dry electric string at the toolkit's 176.4 kHz: `Strings.pluck` at pick position 0.085, trimmed to its decay, read through `Strings.pickup` (neck and bridge groups weighted by BLEND, a humbucker as an aligned coil pair) and a pickup resonance, then the melodic output chain down to 44.1 kHz. The amp is the rack's VALVE: `Magnet.landingChain(voice)` returns an `FxChain` with a `valve` section, applied by recipe. `MagnetPatch.kt` is the saved sound. Everything else is registration, a kit, tests and an audition generator.

**Tech Stack:** Kotlin/JVM, `kotlin.test`, Gradle, JDK 17.

**Spec:** `docs/superpowers/specs/2026-09-29-magnet-valve-design.md` (read "Architecture", "Voices", "Macros", "Testing", "Phasing and gates"). The spike's working model is in `docs/superpowers/plans/2026-09-29-magnet-phase-0-spike.md` (the `CoilSpike` object: `voicePickup` about line 1410, `outputChain` about 1469). R0 (`Strings.combDelay`, `Strings.pickup`) is `docs/superpowers/plans/2026-09-30-magnet-r0.md`. The recon behind this plan, with file:line anchors, is in the workspace `.superpowers/sdd/2026-09-30-magnet-r1/recon-{a,b,c,d}-*.md` (gitignored; the facts below are copied from it).

## Rulings made before execution (each can be undone by the owner)

1. **f0 comes from `Keys.midiHz(rootMidi + snappedSemitones)`**, the route FORK and BORE use (JANGLE root MIDI 40, CHUG 35), not the spike's literal 82.41 / 61.74 Hz (0.065 and 0.129 cents apart, but the seed hashes `f0`). One function (`Magnet.frequencyFor`) feeds the render, the seed and every tuning test.
2. **The string budget is the spike's**: `Strings.pluck(f0, 4.0f, ...)` then `Strings.trimToDecay(raw, rate, 0.25f, 4.0f)`. It is the only rule with data behind it (the spike's MUTE-length numbers), and the spec says only "trimToDecay(0.25 .. 4 s)". Silk's MUTE-driven budget would need a per-voice `ring` constant nothing supplies.
3. **PICK is `Dsp.expMap(PICK, 600f, 16_000f)` for both voices** (the spec's default). The spec's claim that this map passes "each tenth of travel moves the centroid at least 1 %" has never been measured, and a projection from the spike's table says it fails at the top one or two tenths. So: the monotonic clause is asserted; the 1 % clause is **printed, not asserted**; and the velocity registration (`Velocity.brightnessOverride`) is **not made in R1**: MAGNET takes the `soften` fallback, pinned by a test, until a later commit proves the clause on the built engine. Nothing is loosened silently: the spec's rule is "print both numbers, record the measurement".
4. **BLEND weights are linear, positions fixed.** Neck group at position 0.42 with weight `1 - BLEND`, bridge group at 0.12 with weight `BLEND`; each group is ONE `Strings.pickup` call (R0 ruling 1: alignment is inside a group, never between neck and bridge). A humbucker group is two positions `p` and `p + dp` with `dp = 0.0278 * f0 / rootHz` and per-coil weight `0.707 * w`. A call whose weight is exactly 0 is skipped. One `Dsp.TptSvf` resonance runs after the sum (it is linear, so this equals the spike's per-pickup resonance).
5. **The output chain is copied into `Magnet.kt`** (band limit, decimate, mean removal and 20 Hz high-pass, `levelTo` the melodic target, `fadeTail`), as Silk, Fork and Bore each carry their own; `Bore.condition` and `Bore.finish` (`Bore.kt` about 725-750, with rasp and bite at zero) are the authority for the exact calls. Silk's chain is NOT the template (it has no band limit and no DC stage).
6. **Scramble before presets exist** is Silk's defaults-only form (`Dsp.scrambleNear(base [+ near], temperature, random)`); Fork's, Bore's and Thump's seed from a preset roster and would throw on MAGNET's empty one. All four macros roll, TUNE included.
7. **The landing chain is `Magnet.landingChain(voice)`**, living in `Magnet.kt` beside `LANDING_VALVE`, never returning null, and never routed through `Presets.landingFor` (that would break `StringMachineTest`'s "exactly four"). Values: JANGLE `DRIVE 0.25, TONE 0.55, CAB 0.35` (SAG left at VALVE's default 0.35); CHUG `DRIVE 0.71, SAG 0.4, TONE 0.3, CAB 0.95`. The spec's CHUG DRIVE 0.85 was written on V1's gain law, where it meant gain 13; on the V1.1 law gain 13 is DRIVE 0.71 and 0.85 would be gain 106. These are *shape* values for the gate to re-derive by ear, and the audition offers candidates.
8. **Pitch is read two ways, never by `Pitch.detect` against a tight bar.** The dry tuning claim (within 5 cents) is read on the raw 176.4 kHz buffer with `FineTuning`. The through-VALVE claim uses the interpolated `BoreMeasure.cents` on the dry and wet renders; `Pitch.detect` is integer-lag (one step is up to 12.9 cents at JANGLE E4) and can return null or an octave through a hot amp.
9. **No new shared measurement helpers are copied a third time**: tests reuse `FineTuning`, `BoreMeasure`, `PluckSpectra` and `FeatureExtractor`; the few lines that exist only as private copies (`amplitudeAt`, `db`) are copied once into one new test object `MagnetMeasure`.
10. **Humbucker parity.** The aligned pair's notch is 34.1 dB under the single coil where the delay difference is even and about 32 dB where it is odd (R0 measured 32.2); both clear the spec's 20 dB bar. Tests read `Strings.combDelay` at run time and print the parity instead of hard-coding a cell.
11. **The kit is built inline** (defaults plus TUNE, in `SynthKits.magnet()`), all pads `DrumClass.TONAL`, with no preset lookups; A15-A16 (the LEAD family) are CHUG with BLEND 0.35 and a hotter chain written in the kit. Throwaway by the spec's own rule.
12. **The audition page is built by hand as a private artifact**, as V1's was, from the generator's clips and manifest; no per-engine HTML page is added to the repo (none supports a blind or A/B question). The generator writes WAVs and a flat manifest only.

## Review Focus

1. **Every corner and every note**: all 16 macro corners and all 25 TUNE steps of both voices render finite, inside -1..1, centred, and at the melodic level, including the shortest renders (JANGLE E4 at MUTE 1 is about 0.26 s, shorter than the 0.4 s some measures assume).

```kotlin
import com.snipsnap.audio.FeatureExtractor
import com.snipsnap.audio.Loudness

 * MAGNET's contract (docs/superpowers/plans/2026-09-30-magnet-r1.md): the macros, the notes,
 * a deterministic clean render at every corner, the patch's refusals and round trip, the
 * landing chain, and the velocity fallback. The measured claims (tuning, the comb, the

        // E2 and B1 on Keys.midiHz; a tenth of a semitone either side of a step is the same note.
        val e2 = 82.4069f
        val b1 = 61.7354f
        for ((voice, root) in listOf(MagnetVoice.JANGLE to e2, MagnetVoice.CHUG to b1)) {
            assertEquals(root, Magnet.frequencyFor(voice, 0f), 0.01f, "$voice open string")
            assertEquals(2 * root, Magnet.frequencyFor(voice, 0.5f), 0.02f, "$voice one octave up")
            assertEquals(4 * root, Magnet.frequencyFor(voice, 1f), 0.04f, "$voice two octaves up")
            assertEquals(Magnet.frequencyFor(voice, 0.5f), Magnet.frequencyFor(voice, 0.5f + 0.4f / 24f), "$voice snaps to the nearest semitone")
        }
        assertEquals(40, Magnet.rootMidi(MagnetVoice.JANGLE))
        assertEquals(35, Magnet.rootMidi(MagnetVoice.CHUG))
        assertEquals(24, Magnet.TUNE_SEMITONES)
    }

    fun `a render is deterministic and mono at the rack's rate`() {
        for (v in voices) {
            val a = Magnet.render(v)
            val b = Magnet.render(v)
            assertContentEquals(a.samples, b.samples, "$v")
            assertEquals(1, a.channels)
            assertEquals(Dsp.RATE, a.sampleRate)
        }
    }

    @Test
    fun `every corner renders clean, centred, audible audio`() {
        // All 2^4 corners of the four macros, both voices.
        var worstDc = 0.0
        for (v in voices) {
            val specs = Magnet.macrosFor(v)
            for (mask in 0 until 16) {
                val macros = specs.mapIndexed { i, s -> s.name to (if ((mask and (1 shl i)) != 0) 1f else 0f) }.toMap()
                val s = Magnet.render(v, macros)
                val label = "$v $macros"
                assertTrue(s.samples.isNotEmpty(), label)
                assertTrue(s.samples.all { it.isFinite() && it in -1f..1f }, "$label has a bad sample")
                var sum = 0.0
                var peak = 0f
                for (x in s.samples) { sum += x; peak = maxOf(peak, abs(x)) }

                worstDc = maxOf(worstDc, dc)
                assertTrue(dc < DC_BOUND, "$label is off centre by $dc")

            }
        }
```

```kotlin
package com.snipsnap.synth

import com.snipsnap.audio.Snip
import kotlin.math.roundToInt
import kotlin.random.Random

/**
 * MAGNET's voices: a single-coil guitar on its low E (JANGLE) and a humbucker guitar on its low
 * B (CHUG). Top level and named exactly this: the user-preset roster law resolves the voice enum
 * by the engine's name.
 */
enum class MagnetVoice { JANGLE, CHUG }

/**
 * MAGNET - an electric guitar string, dry, ready for VALVE (the rack's amp section).
 *
 * The string is [Strings.pluck] at a pick position of 0.085 of the string (the spike's 0.10 left a
 * fixed hole at the tenth harmonic on every note), trimmed to its decay, read through a pickup:
 * Jaffe and Smith's position comb on the string's output ([Strings.pickup]), neck and bridge
 * weighted by BLEND, a humbucker as two aligned coils, then the pickup's resonance. The rest is the
 * melodic output chain. The amp is not in here: [landingChain] is the recipe that lands a pad
 * through VALVE, and the engine's own render is dry.
 *
 * TUNE is two octaves snapped to semitones from the open string; MUTE damps the loop and shortens
 * the note; PICK is the exciter's low-pass corner, a thumb to a wire; BLEND weights the two pickups
 * (0 neck, 1 bridge). Every number marked shape is a listening value from the Phase-0 spike or the
 * specification, held until the R1 audition (docs/superpowers/specs/2026-09-29-magnet-valve-design.md).
 */
object Magnet {

    /** TUNE: two octaves, snapped to semitones (every melodic engine's rule). */
    const val TUNE_SEMITONES = 24

    /** The string is rendered at the toolkit's oversampled rate and brought down by the output chain. */
    internal const val RENDER_RATE = Dsp.RATE * Dsp.OVERSAMPLE

    /** The string's budget and the trim's floor: the spike's rule (the only one with measurements behind it). */
    private const val STRING_SECONDS = 4.0f
    private const val FLOOR_SECONDS = 0.25f

    /** The exciter's corner at PICK 0 and 1 (shape): a thumb to a wire, wider than the spike's 4.6x. */
    private const val PICK_MIN_HZ = 600f
    private const val PICK_MAX_HZ = 16_000f

    /** Where the pick plucks, as a fraction of the string (shape): the exciter's first comb notch falls between harmonics. */
    private const val PICK_POSITION = 0.085f

    /** The pickups' positions from the bridge, as a fraction of the string (shape). */
    internal const val NECK = 0.42f
    internal const val BRIDGE = 0.12f

    /** A humbucker's coil spacing over an open string, 18 mm of 648 mm (shape); it grows as the string shortens. */
    private const val COIL_SPACING = 0.0278f

    /** Each coil of a humbucker, summed. */
    private const val HUMBUCKER_WEIGHT = 0.707f

    /** The output chain's DC corner. */
    private const val OUTPUT_DC_HZ = 20f

    private class Spec(
        val rootMidi: Int,
        val bodyLoopHz: Float,
        val resonanceHz: Float,
        val resonanceDamping: Float,
        val humbucker: Boolean,
    )

    private fun specFor(voice: MagnetVoice): Spec = when (voice) {
        MagnetVoice.JANGLE -> Spec(rootMidi = 40, bodyLoopHz = 7_000f, resonanceHz = 4_500f, resonanceDamping = 0.40f, humbucker = false)
        MagnetVoice.CHUG -> Spec(rootMidi = 35, bodyLoopHz = 5_500f, resonanceHz = 2_800f, resonanceDamping = 0.55f, humbucker = true)
    }

    fun macrosFor(voice: MagnetVoice): List<MacroSpec> = when (voice) {
        MagnetVoice.JANGLE -> listOf(
            MacroSpec("TUNE", 0.5f, neutral = 0.5f),
            MacroSpec("MUTE", 0.15f),
            MacroSpec("PICK", 0.6f),
            MacroSpec("BLEND", 0.5f),
        )
        MagnetVoice.CHUG -> listOf(
            MacroSpec("TUNE", 0.5f, neutral = 0.5f),
            MacroSpec("MUTE", 0.35f),
            MacroSpec("PICK", 0.55f),
            MacroSpec("BLEND", 1.0f),
        )
    }

    fun defaults(voice: MagnetVoice): Map<String, Float> = macrosFor(voice).associate { it.name to it.default }

    /** The macros as a render sees them: defaults, then each known key clamped to 0..1; unknown keys are dropped. */
    internal fun settled(macros: Map<String, Float>, voice: MagnetVoice): Map<String, Float> {
        val m = defaults(voice).toMutableMap()
        for ((k, v) in macros) if (m.containsKey(k)) m[k] = v.coerceIn(0f, 1f)
        return m
    }

    fun rootMidi(voice: MagnetVoice): Int = specFor(voice).rootMidi

    /** The snapped number of semitones TUNE lands on above the open string. */
    fun semitonesFor(tune: Float): Int = (tune.coerceIn(0f, 1f) * TUNE_SEMITONES).roundToInt()

    /** The note TUNE lands on: the one function the render, the seed and every tuning test read. */
    fun frequencyFor(voice: MagnetVoice, tune: Float): Float = Keys.midiHz(rootMidi(voice) + semitonesFor(tune))

    /** A roll from the defaults (no preset roster exists yet to seed from); [near] pulls it toward a patch. */
    fun scramble(voice: MagnetVoice, random: Random, temperature: Float = 0.35f, near: Patch? = null): Map<String, Float> {
        val base = defaults(voice)
        val seed = if (near != null) base + near.macros.filterKeys { it in base } else base
        return Dsp.scrambleNear(seed, temperature, random)
    }

    /**
     * The amp each voice lands through (shape, re-derived at the R1 audition). DRIVE is a gain on
     * VALVE's law: CHUG's 0.71 is gain 13, which is what the specification meant by 0.85 when it was
     * written on VALVE V1's law (on the V1.1 law 0.85 is gain 106). JANGLE's chain sets no SAG, so VALVE's
     * default 0.35 applies.
     */
    val LANDING_VALVE: Map<MagnetVoice, Map<String, Float>> = mapOf(
        MagnetVoice.JANGLE to mapOf("DRIVE" to 0.25f, "TONE" to 0.55f, "CAB" to 0.35f),
        MagnetVoice.CHUG to mapOf("DRIVE" to 0.71f, "SAG" to 0.4f, "TONE" to 0.3f, "CAB" to 0.95f),
    )

    /** The rack chain that lands a [voice] pad through VALVE. Never null: MAGNET has no loop mode. */
    fun landingChain(voice: MagnetVoice): FxChain = FxChain().withSection("valve", LANDING_VALVE.getValue(voice))

    /** The dry electric string at [RENDER_RATE], before any pickup: trimmed to its decay. */
    internal fun string(voice: MagnetVoice, macros: Map<String, Float>): FloatArray {
        val m = settled(macros, voice)
        val spec = specFor(voice)
        val f0 = frequencyFor(voice, m.getValue("TUNE"))
        val damping = Strings.damping(m.getValue("MUTE"), spec.bodyLoopHz)
        val pickHz = Dsp.expMap(m.getValue("PICK"), PICK_MIN_HZ, PICK_MAX_HZ)
        val seed = Dsp.seedFor("MAGNET", voice.name, f0)
        val raw = Strings.pluck(f0, STRING_SECONDS, damping, pickHz, seed, RENDER_RATE, position = PICK_POSITION)
        return Strings.trimToDecay(raw, RENDER_RATE, FLOOR_SECONDS, STRING_SECONDS)
    }

    /**
     * The string read through the pickups at [f0] and [blend] (0 neck alone, 1 bridge alone): the
     * neck group at [neck] weighted `1 - blend`, the bridge group at [bridge] weighted `blend`, each
     * ONE [Strings.pickup] call (a humbucker group is its two coils, aligned; the two groups are
     * never aligned to each other), summed, then the pickup's resonance unless [resonance] is false.
     * The position and resonance arguments exist so a test can read the comb alone.
     */
    internal fun pickup(
        voice: MagnetVoice,
        y: FloatArray,
        f0: Float,
        blend: Float,
        resonance: Boolean = true,
        neck: Float = NECK,
        bridge: Float = BRIDGE,
    ): FloatArray {
        val spec = specFor(voice)
        val dp = COIL_SPACING * f0 / Keys.midiHz(spec.rootMidi)
        val b = blend.coerceIn(0f, 1f)
        val out = FloatArray(y.size)
        fun add(position: Float, weight: Float) {
            if (weight == 0f) return
            val positions = if (spec.humbucker) floatArrayOf(position, position + dp) else floatArrayOf(position)
            val each = if (spec.humbucker) HUMBUCKER_WEIGHT * weight else weight
            val combed = Strings.pickup(y, positions, FloatArray(positions.size) { each }, f0, RENDER_RATE)
            for (i in out.indices) out[i] += combed[i]
        }
        add(neck, 1f - b)
        add(bridge, b)
        if (!resonance) return out
        val svf = Dsp.TptSvf(RENDER_RATE)
        for (i in out.indices) {
            svf.process(out[i], spec.resonanceHz, spec.resonanceDamping)
            out[i] = svf.low
        }
        return out
    }

    /**
     * The melodic output chain, copied from the other engines' (`Bore.condition` and `Bore.finish`
     * with rasp and bite at zero are the authority for the exact calls): band-limit, decimate to the
     * rack's rate, remove the mean and the DC corner, level to the melodic target, fade the tail.
     * Works in place on [buf] and returns the rack-rate samples.
     */
    internal fun finish(buf: FloatArray, rate: Int): FloatArray {
        Tide.bandLimit(buf, rate)
        val out = Dsp.decimate(buf, Dsp.RATE)
        var sum = 0.0
        for (v in out) sum += v
        val mean = if (out.isEmpty()) 0f else (sum / out.size).toFloat()
        val hp = Dsp.OnePole(Dsp.RATE)
        for (i in out.indices) {
            val x = out[i] - mean
            out[i] = x - hp.lp(x, OUTPUT_DC_HZ)
        }
        Dsp.levelTo(out, Dsp.RATE, Dsp.MELODIC_LOUDNESS_TARGET)
        Dsp.fadeTail(out)
        return out
    }

    /** One dry note at the rack's rate. The seed is part of the sound: it is derived, never an argument. */
    fun render(voice: MagnetVoice, macros: Map<String, Float> = emptyMap()): Snip {
        val m = settled(macros, voice)
        val f0 = frequencyFor(voice, m.getValue("TUNE"))
        val picked = pickup(voice, string(voice, m), f0, m.getValue("BLEND"))
        return Snip(finish(picked, RENDER_RATE), channels = 1, sampleRate = Dsp.RATE)
    }
}
```
