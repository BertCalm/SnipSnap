# GYRE Round Two Implementation Plan (R2a and R2b)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give GYRE its bow. First a bridge port on `Strings.Bow` (R2a, its own PR, no audio change to ARCO). Then GYRE's strings become two segments, TOUCH joins as the sixth macro and morphs each string's excitation from pluck to bow, and two bowed voices, DRAWN and BOURDON, join FLICK and HALO, with an audition page for the round-two gate (R2b).

**Architecture:** R2a adds to `Strings.kt` an in-flight read and write on `Strings.Loop` (`inFlight`, `setInFlight`), and on `Strings.Bow` a bridge port (`bridgeAge`, `atBridge`, `toBridge`) and a second `next` that takes an excitation and a contact amount. Nothing that does not call them changes, proven against a frozen copy of the bow. R2b rebuilds `Gyre.play` on four `Strings.Bow`s: the bridge coupling (`Strings.Bridge.couple`, unchanged) moves to the bridge ports, the pluck enters and the sound leaves there too, and TOUCH lowers the bow onto the strings. No presets, kit or phone UI this round (R5 and R5.1); the circular bow, LATHE and WIRE are R3; the LOOP is R4.

**Tech Stack:** Kotlin/JVM, `kotlin.test`, Gradle, JDK 17.

**Spec:** `docs/superpowers/specs/2026-10-01-gyre-coupled-string-engine-design.md`: G1 (the bow is ARCO's), G3 and "Where the bridge is, once there is a bow", "Architecture" (TOUCH), "Testing", "Phasing and gates" (R2), and "Decisions taken". The source document's §5.2 (the friction exciter's required behaviour), §6 (the TOUCH morph), §14 (ARC and DRONE, here DRAWN and BOURDON), §15 (macro defaults by voice) and §21 (durations).

### What Phase 0 found

1. **The bridge port needs no surgery on the bow's delay lines.** The spec proposed splitting the bridge segment into two one-way delays. That does not survive a retune sample for sample: a vibrato moves the read point, and with a split the move lands half a round trip late. Instead the port reads and rewrites the sample in flight at half the bridge segment's length (`Loop.inFlight`), and the segment's own reflection (the 0.95 loss and the corner) stays where it is. A port that writes back what it read is the bow as it was, retunes included, sample for sample (`StringsBowPortTest`).
2. **FLICK and HALO survive the move to two segments.** With the pluck entering and the sound leaving at the bridge port (as R1's single junction did), TOUCH 0 on two segments against the merged R1c, at G3, C4 and G4: the same pitch to 0.1 cents; the waveform difference 14 to 28 dB under the note; the octave bands within 0.09 to 1.49 dB (FLICK's G3 is the largest). Plucking under the bow and listening there instead moved the bands 1.9 to 3.9 dB and the waveform difference was 0 dB: the bow's position combs both.
3. **A bow on a string is a switch unless it lowers gradually.** With the source document's crossfade (bow amount `sin(TOUCH·π/2)`, on full contact), TOUCH 0.1 was already a sustained bowed note: the first tenth of the knob covered 23 of FLICK's 24 units of colour distance (`ArcoBodyMeasure.colour`) and 34 of HALO's 34. A bow resting on the string pins it, however slowly it moves. With a **contact amount** (`next(..., contact)`, the push scaled by it) that rises as `sin(TOUCH·π/2)³`, no 0.1 step covers more than a third of the ends' distance (FLICK 7.8 of 24.0, HALO 11.5 of 34.0). The sustain rises from 20 dB under the attack to 7 above it (FLICK; HALO −13 to +6), and the middle is not a crossfade: TOUCH 0.5 is 4.4 (FLICK) and 4.5 (HALO) units from a 50/50 mix of the two ends.
4. **A bowed string wants ARCO's tuning share, a plucked one the full share.** At share 1 (R1's rule), HALO bowed was 5 to 7 cents sharp. With the share falling from 1 to 0.85 (`Strings.Bow.SHARE`) as the bow lowers, HALO's bowed C4 reads 0.1 cents. FLICK's bowed notes read −3 to −4 cents either way. One reading, FLICK at TOUCH 0.5, was −15.7 cents, where the pluck and the bow compete: Task 3 re-measures it.
5. **Bowed HALO is too loud for the raw ceiling.** With the contact curve, its raw peak reached 1.23, 1.55 and 1.25 at TOUCH 0.8, 0.9 and 1, against `RAW_PEAK_CEILING` 1.25; FLICK's stayed at or under 0.78. The bow's speed (0.13 in the prototype, ARCO's `V_SUSTAIN`) needs a per-voice value (Task 3).

Not measured in Phase 0, left to the tasks: SPIN with a bow on the strings, the 30-second bound at the extremes, DRAWN's and BOURDON's own shapes, and how HOLD reads on a bowed note.

### Decisions for the owner (this plan proposes; the owner confirms before Task 3)

1. **TOUCH's default on FLICK and HALO stays 0.** The source document's table gives FLICK 0.15 and HALO 0.40, but both voices passed the gate as pure plucks. A later listen can move them.
2. **DRAWN and BOURDON start from the document's table:** DRAWN TOUCH 0.85, SYMPATHY 0.45, SPIN 0.12, BODY 0.45; BOURDON TOUCH 0.90, SYMPATHY 0.65, SPIN 0.30, BODY 0.75, an octave lower, darker. Their shapes (Task 4) are first values; the gate decides.
3. **HOLD on a bowed note is how long the bow is drawn.** HOLD keeps the owner's "short and choked up to fully open": at 0 the hand lands 0.04 s after the start, and the open end grows with the bow from the pluck's ring to a **stroke** (DRAWN 4 s, BOURDON 6 s: inside the document's 2-5 s and 3-8 s). Past the stroke the bow lifts and the note rings out as R1c's does.
4. **The bow plays all four strings, weighted by the voice's string levels** (as the pluck does), not string 1 alone. A bow on one string with the others driven only through the bridge is R3's circular-bow territory.

```kotlin
package com.snipsnap.synth

import com.snipsnap.synth.Dsp.RATE
import kotlin.math.abs
import kotlin.test.Test
import kotlin.test.assertContentEquals
import kotlin.test.assertEquals

/**
 * GYRE R2a: `Strings.Bow`'s bridge port, excitation input and contact amount change nothing for a bow
 * that does not use them (docs/superpowers/specs/2026-10-01-gyre-coupled-string-engine-design.md, G3,
 * "Where the bridge is, once there is a bow"). [LegacyBow] is the bow as it was. Every grid cell plays
 * a stroke with an attack, a few cents of stepped vibrato (the retune path) and a lift with a stop, so
 * every hook a caller has is exercised.
 */
class StringsBowPortTest {

    private val rate = RATE * Dsp.OVERSAMPLE

    private class Cell(val f: Float, val beta: Float, val pressure: Float)

    private val grid = listOf(
        Cell(65.41f, 0.133f, 0.9f), Cell(130.81f, 0.133f, 0.5f), Cell(130.81f, 0.3f, 0.9f),
        Cell(220f, 0.08f, 0.7f), Cell(440f, 0.133f, 0.9f), Cell(880f, 0.133f, 0.7f),
    )

    /** A stroke: [len] samples, the bow's velocity and slope at each, a retune every 64 samples from a quarter in, a lift at 70 percent. */
    private fun stroke(len: Int, c: Cell, next: (Float, Float) -> Float, retune: (Float) -> Unit, lift: () -> Unit, gain: (Float) -> Unit): FloatArray {
        val attack = len / 10
        val liftAt = len * 7 / 10
        return FloatArray(len) { i ->
            if (i >= len / 4 && i < liftAt && i % 64 == 0) retune(c.f * (1f + 0.002f * ((i / 64) % 3)))
            if (i == liftAt) { lift(); gain(0.9f) }
            val v = if (i < attack) 0.13f * i / attack else 0.13f
            next(v, 5f - 4f * c.pressure)
        }
    }

    private fun legacy(c: Cell, len: Int): FloatArray {
        val bow = LegacyBow(c.f, c.beta, rate = rate)
        return stroke(len, c, bow::next, bow::retune, bow::lift, bow::gain)
    }

    @Test
    fun `a bow that uses none of it is the frozen bow, sample for sample`() {
        val len = rate / 2
        for (c in grid) {
            val bow = Strings.Bow(c.f, c.beta, rate = rate)
            val now = stroke(len, c, bow::next, bow::retune, bow::lift, bow::gain)
            assertContentEquals(legacy(c, len), now, "${c.f} Hz, beta ${c.beta}, pressure ${c.pressure}")
        }
    }

    @Test
    fun `a bridge that leaves every wave as it found it changes nothing`() {
        val len = rate / 2
        for (c in grid) {
            val bow = Strings.Bow(c.f, c.beta, rate = rate)
            val now = stroke(len, c, { v, s -> bow.toBridge(bow.atBridge()); bow.next(v, s, 0f, 1f) }, bow::retune, bow::lift, bow::gain)
            assertContentEquals(legacy(c, len), now, "${c.f} Hz, beta ${c.beta}, pressure ${c.pressure}")
        }
    }

    @Test
    fun `a bow at no contact is a lifted bow`() {
        // Both struck with the same burst and bowed at full speed: the lifted one ignores the bow, the
        // one at contact 0 must too, sample for sample (a silent pair would prove nothing).
        val len = rate / 4
        val burst = FloatArray(64) { if (it < 32) 0.5f else -0.5f }
        for (c in grid) {
            val lifted = Strings.Bow(c.f, c.beta, rate = rate).also { it.lift() }
            val light = Strings.Bow(c.f, c.beta, rate = rate)
            val a = FloatArray(len) { i -> lifted.next(0.13f, 5f - 4f * c.pressure, if (i < burst.size) burst[i] else 0f) }
            val b = FloatArray(len) { i -> light.next(0.13f, 5f - 4f * c.pressure, if (i < burst.size) burst[i] else 0f, 0f) }
            assertTrue(a.any { it != 0f }, "${c.f} Hz: the burst made no sound")
            assertContentEquals(a, b, "${c.f} Hz")
        }
    }

    @Test
    fun `an excitation is heard at the bow's pitch and rings down as the string does`() {
        // A lifted bow struck once with a short burst rings at its note: the excitation enters both waves
        // under the bow, so the string's own period sets the pitch, and doubling it doubles every sample
        // (to Float's rounding: the loop's filters round each product, exactly only while it is normal).
        // A free string is tuned at the full share (tune's own rule): SHARE is a bowed string's correction
        // and leaves a free one flat (measured at the pinned share: 440 Hz rings 5.7 cents low).
        for (f in floatArrayOf(130.81f, 440f)) {
            val one = Strings.Bow(f, 0.133f, share = 1f, rate = rate).also { it.lift() }
            val two = Strings.Bow(f, 0.133f, share = 1f, rate = rate).also { it.lift() }
            val burst = FloatArray(64) { if (it < 32) 0.5f else -0.5f }
            val a = FloatArray(rate) { i -> one.next(0f, 5f, if (i < burst.size) burst[i] else 0f) }
            val b = FloatArray(rate) { i -> two.next(0f, 5f, if (i < burst.size) 2f * burst[i] else 0f) }
            val top = a.maxOf { abs(it) }
            for (i in a.indices) assertTrue(abs(b[i] - 2f * a[i]) <= 1e-6f * top, "$f Hz sample $i: ${b[i]} against ${2f * a[i]}")
            val decimated = Dsp.decimate(a.copyOf(), RATE)
            val cents = FineTuning.cents(FineTuning.measuredHz(decimated, RATE, f, 0.05f, 0.3f), f.toDouble())
            println("$f Hz: an excited, lifted bow rings at ${"%.1f".format(cents)} cents")
            assertTrue(abs(cents) < 5.0, "$f Hz: an excited bow rings $cents cents off")
        }
    }

    @Test
    fun `a wave put at the bridge reaches the bow about half a bridge round trip later`() {
        // Read at the bow (bowPoint, both arriving waves): next's own return is the wave leaving toward
        // the bridge, which has been round the nut segment first.
        val bow = Strings.Bow(220f, 0.133f, rate = rate).also { it.lift() }
        for (i in 0 until 2_000) bow.next(0f, 5f)
        bow.toBridge(1f)
        var first = -1
        for (i in 0 until 2_000) { bow.next(0f, 5f); if (bow.bowPoint != 0f && first < 0) first = i }
        println("bridge port at ${bow.bridgeAge} samples; the wave reached the bow after $first")
        assertTrue(abs(first - bow.bridgeAge) <= 2, "the port is ${bow.bridgeAge} samples from the far end, the wave took $first")
    }

    @Test
    fun `a contact outside 0 to 1 is refused`() {
        val bow = Strings.Bow(220f, 0.133f, rate = rate)
        assertFailsWith<IllegalArgumentException> { bow.next(0.1f, 2f, 0f, 1.5f) }
        assertFailsWith<IllegalArgumentException> { bow.next(0.1f, 2f, 0f, -0.1f) }
    }
}
```

```kotlin
        /**
         * One sample with [excite] added under the bow, into both waves leaving it (a pluck or a strike at
         * the bow's place on the string), and the bow's push scaled by [contact], in [0, 1]: 0 is a lifted
         * bow, 1 is full contact. With nothing added and full contact this is [next] without them, taken
         * as its own path, so a bow that uses neither runs the same operations as before.
         */
        fun next(vBow: Float, slope: Float, excite: Float, contact: Float = 1f): Float {
            if (excite == 0f && contact == 1f) return next(vBow, slope)
            require(contact in 0f..1f) { "the bow's contact is a share of full contact, in [0, 1], got $contact" }
            val fromBridge = bridge.reflected()
            val fromNut = nut.reflected()
            val v = fromBridge + fromNut
            val dv = vBow - v
            val push = (if (bowDown) contact * dv * rho(dv, slope, rhoMax) else 0f) + excite
            nut.inject(fromBridge + push)
            bridge.inject(fromNut + push)
            bowPoint = v + push
            return fromNut + push
        }
```
