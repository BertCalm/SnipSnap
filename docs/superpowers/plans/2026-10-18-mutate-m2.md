## Review Focus

Five inputs the spec implies but its Testing section does not exercise, most likely to bite first. Each is pinned by a test in the task that owns the code.

- **A file picked again under the same name, with a different sound.** `hold` used to name the held WAV after the stem alone, so two picks of `kick.wav` were one equal `Partner.Wav`, and a KEEP lit by the first sound would save the second unheard. The held file now carries its bytes' checksum, so another sound is another partner and plays first; the same sound again is the same partner and costs no extra play. Pinned in Task 1 (`two files picked under one name are two picks, and the same sound picked again is one`) and Task 4 (`a file picked again under its name with another sound is unheard`).
- **A first tap whose play never happened.** The render throws, the partner is gone, or the phone goes to the background while the render runs: KEEP must stay unheard, so the next tap plays again rather than saving. The heard stamp sits inside the lifecycle gate, after `audition(…)`, in both HEAR and KEEP's first tap, and nowhere in a `catch`. Pinned in Task 6 (`law - KEEP plays unheard settings first, and only HEAR, its first tap and its own write say what was heard`).
- **Back with the partner panel open.** The system Back must close the panel and leave the player on the pad sheet, at the MUTATE box, not leave the sheet or land at its top. The panel's own `BackHandler` composes after the sheet's, and the sheet's scroll is held above the panel. Pinned in Task 5 (`law - the partner panel draws only the chooser's rows, says each chip's state, and Back closes it`).
- **Another kit's pad with the same slot as this kit's partner.** With this kit's A02 as the partner and another kit open in the panel, only this kit's A02 may say SELECTED (and the reverse). Pinned in Task 3 (`the partner's own chip, and only it, says SELECTED, and every chip fits its half row`).
- **A source with nothing in it.** A one-pad kit on a one-kit shelf with no room kept: the panel says so in words for each empty source, never an empty gap, and ROULETTE and A FILE are still there to tap. Pinned in Task 3 (`an empty source says so in words, and ROULETTE and A FILE are always there to tap`).

### Task 1: The shared chooser, lifted out of `MutateSheet`

MUTATE's partner picker is the only "which sound" picker in the app, and TERRA's R4 needs the same door for STRUCK BY, BENT BY and STRIKE FROM. The comments in `MutateSheet.kt` that still call the shelf "the crate" (M1's parked item) are reworded where they stand, and the ones on functions that move go with them in the new words.

import com.snipsnap.audio.Snip
import com.snipsnap.audio.WavReader

import com.snipsnap.kit.KitStore

/**
 * Pick a pad: the app's one "which sound" chooser, as data.
 *
 * MUTATE's partner picker was the only one, and the TERRA spec's round R4
 * needs the same door for TERRA's STRUCK BY and BENT BY and FORK's STRIKE
 * FROM. So the MUTATE redesign's round M2 lifts it here once, to R4's
 * description, and R4 reuses it instead of lifting it
 * (`docs/superpowers/specs/2026-10-04-mutate-card-redesign-design.md`,
 * "The shared pick-a-pad component", Decision 8).
 *
 * Five kinds of sound ([Kind]), and each caller offers its own
 * ([kindsFor]): MUTATE all five; STRUCK BY, BENT BY and STRIKE FROM a pad on
 * this kit, a pad on another kit, or a file, never a ROULETTE pick or a
 * room. The picked sound is a [MutateSheet.Partner], the type that stays
 * where it is: a type alias cannot be nested in an object before Kotlin
 * 2.2, and both modules pin 2.0.21, so the type is not moved and no alias
 * is declared (this package already has `Mutate.Pick`, the roulette's own
 * pick). `MutateSheet` delegates its partner functions here under their
 * present names and signatures, so every caller and test compiles as it
 * did.
 */
object PadChooser {

    /** The five kinds of sound the chooser can offer, in the order the panel draws them. */
    enum class Kind { THIS_KIT, OTHER_KIT, ROULETTE, ROOM, FILE }

    /** Who opened the chooser: MUTATE's CHANGE ▸ today; TERRA's and FORK's rows in R4. */
    enum class Caller { MUTATE, STRUCK_BY, BENT_BY, STRIKE_FROM }

    /** The kinds [caller] offers, in the panel's order. */
    fun kindsFor(caller: Caller): List<Kind> = when (caller) {
        Caller.MUTATE -> Kind.values().toList()
        Caller.STRUCK_BY, Caller.BENT_BY, Caller.STRIKE_FROM -> listOf(Kind.THIS_KIT, Kind.OTHER_KIT, Kind.FILE)
    }

    /** The longest a picked sound's name runs: the TERRA spec's `MAX_FROM_CHARS`, which R4 stores. */
    const val NAME_CHARS = 24

    /** Every other assigned pad on [kit], slot order. Never the pad itself. */
    fun candidates(kit: Kit, slot: Int): List<KitPad> = kit.pads.filter { it.slot != slot }.sortedBy { it.slot }

    /**
     * The other kits on the shelf under [shelfRoot], by name, never
     * [thisKitDir] itself. A folder whose `kit.json` is broken is skipped,
     * not fatal. The two folders are told apart by their normalised
     * absolute paths, which never touch the disk (a canonical path would,
     * and could throw).
     */
    fun otherKits(shelfRoot: File, thisKitDir: File): List<MutateSheet.OtherKit> {
        val here = thisKitDir.absoluteFile.normalize()
        return KitStore.list(shelfRoot)
            .filter { it.absoluteFile.normalize() != here }
            .mapNotNull { dir -> runCatching { MutateSheet.OtherKit(KitStore.load(dir).name, dir) }.getOrNull() }
            .sortedBy { it.name.lowercase(java.util.Locale.ROOT) }
    }

    /** The assigned pads of another kit, slot order: the chooser's second step for [Kind.OTHER_KIT]. */
    fun padsOf(kit: MutateSheet.OtherKit): List<KitPad> = KitStore.load(kit.dir).pads.sortedBy { it.slot }

    /**
     * A picked file held: its audio written under [holdDir] as a WAV named
     * after [displayName] (the stem made safe) and stamped with its sound's
     * checksum, landed by write-then-rename like a kept room. The pick's
     * label is the name the file came with, extension and all - what
     * `snipsnap mutate --with hit.wav` puts in the lineage. One is held at a
     * time: the last pick's file goes. A silent file refuses in words.
     *
     * The stamp is why two picks of different sounds under one name are two
     * different picks: without it both are `Wav("kick.wav", …/kick.wav)`, one
     * equal value, and MUTATE's first-tap rule would take a sound it never
     * played for the one it did. The same sound picked again is the same
     * pick, because the stamp is the bytes' own.
     */
    fun hold(holdDir: File, displayName: String, snip: Snip): MutateSheet.Partner.Wav {
        require(snip.frameCount > 0 && snip.peak() > 0f) { "that file is silent - nothing to mutate with" }
        val bare = displayName.substringAfterLast('/').substringAfterLast('\\').trim().ifBlank { "parent.wav" }
        val stem = Names.sanitizeStem(if (bare.contains('.')) bare.substringBeforeLast('.') else bare)
        val bytes = java.io.ByteArrayOutputStream().also { WavWriter.write(it, snip) }.toByteArray()
        val stamp = CRC32().apply { update(bytes) }.value.toString(16).padStart(8, '0')
        holdDir.mkdirs()
        val wav = File(holdDir, "$stem-$stamp.wav")
        holdDir.listFiles()?.forEach { if (it.name != wav.name) it.delete() }
        AtomicFile.writeBytes(wav, bytes)
        return MutateSheet.Partner.Wav(bare, wav)
    }

    /**
     * ROULETTE: the shelf under [root] (the crate, on the CLI) picks a
     * partner for [slot] — guided, never wild, never the pad itself; a new
     * [seed] is a new pick, the same seed the same one. Throws
     * [Mutate.RouletteRefused] (EMPTY or ONLY_COPIES) when the shelf has
     * nothing to pick.
     */
    fun deal(model: KitBuilderModel, slot: Int, root: File, seed: Int): MutateSheet.Partner.Deal {
        val pick = Mutate.roulette(model, slot, root, seed = seed, wild = false)
        return MutateSheet.Partner.Deal(pick.label, pick.file, seed)
    }

    /**
     * The picked sound as [Mutate] wants it; a pad's label is the CLI's own
     * `Kit:A03` form, so the lineage reads the same either way. Each kind
     * is checked before it is read and throws [MutateSheet.PartnerGone] when
     * it is not there; a file that is there but does not decode is a real
     * failure.
     */
    fun source(model: KitBuilderModel, pick: MutateSheet.Partner): Mutate.Source = when (pick) {
        is MutateSheet.Partner.Pad -> {
            val pad = model.pad(pick.slot) ?: throw MutateSheet.PartnerGone("no pad on ${PadBanks.tag(pick.slot)}")
            Mutate.Source("${model.kit.name}:${PadBanks.tag(pick.slot)}", WavReader.read(present(File(model.kitDir, pad.sampleFile))))
        }
        is MutateSheet.Partner.Deal -> Mutate.Source(pick.label, WavReader.read(present(pick.file)))
        is MutateSheet.Partner.Room -> Mutate.Source(Rooms.LABEL_PREFIX + pick.name, WavReader.read(present(pick.file)))
        is MutateSheet.Partner.Other -> {
            // Checked here, because KitStore.load would throw a plain IOException.
            if (!File(pick.kitDir, KitStore.FILE_NAME).isFile) throw MutateSheet.PartnerGone("${pick.kitName} is not on the shelf")
            val kit = KitStore.load(pick.kitDir)
            val pad = kit.pads.firstOrNull { it.slot == pick.slot }
                ?: throw MutateSheet.PartnerGone("no pad on ${pick.kitName} ${PadBanks.tag(pick.slot)}")
            // The CLI's own Kit:Pad label, so the lineage reads the same as a roulette pick's.
            Mutate.Source("${kit.name}:${PadBanks.tag(pick.slot)}", WavReader.read(present(File(pick.kitDir, pad.sampleFile))))
        }
        // The file's own name, as `--with hit.wav` labels it.
        is MutateSheet.Partner.Wav -> Mutate.Source(pick.label, WavReader.read(present(pick.file)))
    }

    /** [file] itself, or [MutateSheet.PartnerGone] when it is not there; WavReader.read would throw a plain IOException. */
    private fun present(file: File): File = if (file.isFile) file else throw MutateSheet.PartnerGone("${file.name} is gone")

    /**
     * The picked sound's name, in capitals, at most [NAME_CHARS]: a pad on
     * this kit by its tag and name (`B07 KICK`, [padName] giving the name),
     * another kit's pad as `SOUL B02`, a ROULETTE pick as the strip names it
     * (`SOUL A03`), a room or a file by its name. A cut never goes through
     * the tag. Control characters are dropped (a picked file's name keeps
     * whatever the phone gave it, and R4's `Striker.from` and `Bend.from`
     * refuse one in `init`); the pick's own label, the lineage's, stays raw.
     */
    fun name(pick: MutateSheet.Partner, padName: (Int) -> String? = { null }): String = cut(
        when (pick) {
            is MutateSheet.Partner.Pad -> listOfNotNull(PadBanks.tag(pick.slot), padName(pick.slot)?.takeIf { it.isNotBlank() }).joinToString(" ")
            is MutateSheet.Partner.Other -> "${pick.kitName} ${PadBanks.tag(pick.slot)}"
            is MutateSheet.Partner.Deal -> PadSheetBoxes.parentName(pick.label)
            is MutateSheet.Partner.Room -> pick.name
            is MutateSheet.Partner.Wav -> pick.label
        }.filterNot { it.isISOControl() }.trimEnd().uppercase(java.util.Locale.ROOT),
        NAME_CHARS,
    )

    /**
     * The display label R4 stores in `Striker.from` and `Bend.from`, and
     * MUTATE's KEEP prints: a pad on this kit by its tag alone (`A03`),
     * every other kind as [name] (`SOUL A03`, a file's name), at most
     * [NAME_CHARS].
     */
    fun label(pick: MutateSheet.Partner): String =
        if (pick is MutateSheet.Partner.Pad) PadBanks.tag(pick.slot) else name(pick)

    /** A pad tag at the start of a name (`A02 SNARE`) or at its end (`SOUL B02`): [PadBanks.tag]'s shape. */
    private val LEADING_TAG = Regex("""^[A-Z]\d{2}(?= |$)""")
    private val TRAILING_TAG = Regex("""(?<=^| )[A-Z]\d{2}$""")

    /**
     * [name] cut to [max] characters, ending in `…` where it is cut, never
     * through a pad tag: a leading tag stays whole (`A02 SNA…`), so does a
     * trailing one (`SO… B02`), and where not one character of the rest
     * fits, the tag stands alone. A name with no tag (a room, a file) is
     * cut at the end. A cut never splits a surrogate pair ([whole]).
     */
    internal fun cut(name: String, max: Int): String {
        if (name.length <= max) return name
        LEADING_TAG.find(name)?.let { m ->
            val rest = name.substring(m.value.length).trimStart()
            val keep = max - m.value.length - 2 // a space and the ellipsis
            return if (keep < 1 || rest.isEmpty()) m.value else "${m.value} ${whole(rest, keep).trimEnd()}…"
        }
        TRAILING_TAG.find(name)?.let { m ->
            val head = name.substring(0, m.range.first).trimEnd()
            val keep = max - m.value.length - 2
            return if (keep < 1 || head.isEmpty()) m.value else "${whole(head, keep).trimEnd()}… ${m.value}"
        }
        return whole(name, max - 1).trimEnd() + "…"
    }

    /** The first [n] characters of [s], one fewer where the last would be the first half of a surrogate pair. */
    private fun whole(s: String, n: Int): String =
        if (n in 1 until s.length && s[n - 1].isHighSurrogate()) s.take(n - 1) else s.take(n)
}

        data class OpenKit(val kit: MutateSheet.OtherKit) : Choice

                ActionButton(PadChooser.CANCEL_LABEL, scheme, enabled = !busy, onClick = onDismiss)
            }
            Column(
                Modifier.weight(1f).fillMaxWidth().verticalScroll(rememberScrollState()),
                verticalArrangement = Arrangement.spacedBy(4.dp),
            ) {
                for (row in rows) {
                    when (row) {
                        is PadChooser.Row.Heading -> TapeText(row.text, TapeType.pixelSmall, scheme.ink3.tape, maxLines = 1)
                        is PadChooser.Row.Note -> TapeText(row.text, TapeType.pixelSmall, scheme.ink3.tape, maxLines = 1)
                        is PadChooser.Row.Chips -> Row(Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.spacedBy(4.dp)) {
                            for (chip in row.chips) {
                                Box(
                                    Modifier
                                        .weight(1f)
                                        .heightIn(min = Layout.MIN_HIT_TARGET.dp)
                                        .raisedBevel(scheme, fill = if (chip.selected) padColor.copy(alpha = 0.85f) else null)
                                        // Always clickable, `!busy` forwarded rather than
                                        // dropped (accessibility audit finding 12). The
                                        // spoken label is the name uncut, and says SELECTED.
                                        .tapeClick(label = chip.spoken, enabled = !busy) { onChoose(chip.choice) }
                                        .padding(horizontal = 4.dp),
                                    contentAlignment = Alignment.Center,
                                ) {
                                    TapeText(
                                        chip.label,
                                        TapeType.pixel,
                                        if (busy) scheme.ink3.tape else if (chip.selected) scheme.titleInk.tape else scheme.ink2.tape,
                                        maxLines = 1,
                                    )
                                }
                            }
                            // A short last row keeps the same chip width as a full one.
                            repeat(2 - row.chips.size) { Spacer(Modifier.weight(1f)) }
                        }
                        is PadChooser.Row.Action -> ActionButton(
                            row.label,
                            scheme,
                            enabled = !busy,
                            accessibilityLabel = row.spoken,
                            modifier = Modifier.fillMaxWidth(),
                            onClick = { onAction(row.kind) },
                        )
                    }
                }
            }
        }
    }
}
