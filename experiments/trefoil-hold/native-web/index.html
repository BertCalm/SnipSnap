Implementation, measurements & source

The six Kotlin reference cases passed an independent Python check. Shared-force relative error energy is below 6.8e-16. All 88 approved finite-bank WAVs and both program files are byte-identical after the port.

Host captures take about .6 seconds uncached after warmup; prepared cache hits take under 1 ms. Cold preparation remains a performance limit. The Android build compiles, and the source includes an on-device benchmark. Physical phone timings and this held trial's MPC response remain to be measured.
