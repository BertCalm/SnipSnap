# Accepted coupled snare

The owner accepted **Stronger snare snap and rattle** on 17 November 2026:
“Ok. I can live with that”. Integration preserves those nine PCM files exactly.
Only Roadhouse pad 2 changes; the other snares have not been auditioned with this model.

`model.cpp` and `render.py` preserve the accepted mechanics and output stage.
Compile `g++ -O3 -shared -fPIC model.cpp -o model.so`, then run
`OPENBLAS_NUM_THREADS=1 python3 render.py /tmp/coupled-snare-proof` with NumPy/SciPy.
The immutable `soul-rock/v2` resources and their hashes remain the accepted delivery.
`verification.json` also documents earlier listening files, which this small renderer
intentionally does not regenerate. Host platform/compiler changes can affect float output.

The bank retains natural take levels, no per-take normalization. This is frozen synthesis,
not an editable Kotlin engine. Full alias convergence and phone/MPC hardware are open.

Integration verification on 17 November 2026 reproduced all nine WAVs byte-for-byte
on the current host using this retained source, then pinned their hashes in Kotlin.
