Make a playable instrument

In SnipSnap, open SYNTH → CONTOUR, choose a recipe and edit its controls. Select MAKE INSTRUMENT, set RELEASE and tap MAKE. The complete recipe supplies the tone; the keyboard supplies pitch and held playback.

For the CLI, download a recipe above and use the matching voice shown on its card:

java -jar snipsnap.jar synth CONTOUR KEY --patch "Copper Scan.json" --instrument --release .6 --out contour-keys

Keep the exported .xty track and .instrument.json phone metadata beside the matching _[TrackData]/ folder. That folder contains the shared WAVs and MPC 2 .xpm twin.

To regenerate all 36 programs and the checked ZIP from the source checkout:

./gradlew :shell:generateContourStarter
Playback and verification
  • Preview files contain one exact settled period from the exported root sample, encoded as mono PCM16 at 44.1 kHz. Browser playback loops that period with a 5 ms gain fade at start and stop.
  • Preview level is the captured instrument level. No audition matching or rack effects are added here. Start with your listening volume low.
  • The full instrument uses PCM24 samples. Only the first 5 ms of its entry are softened; the repeating cycle remains unchanged.
  • ATTACK, DECAY and the transient filter contour do not retrigger in these captured sustains. Saved excitation velocity shapes the captured tone; the instrument has one sampled velocity layer.
  • Export checks read back sample roots, keyboard ranges, loop markers, native track data and compatibility programs. Physical Android and MPC playback remain unchecked.
