What is being tested?

Listen for kick weight, snare attack, cymbal fizz, the shape of the spring splash, and whether the moving tail overwhelms the groove. ROOM changes early reflections; GRIT changes recording saturation; SPLASH changes spring excitation and return; SWEEP and RATE control the phaser; DRIVE changes amp gain.

The two-mic source is a fixed delay/filter/balance model. Spring dispersion is a new approximation, not a measured hardware emulation. Each phrase shares one effect state; isolated hits restart it. Matched gain uses SnipSnap’s loudest 200 ms RMS meter, not LUFS.
