C

CICADA's lattice

Does the inner re-clocking read as its own texture?

CICADA restarts its carrier CICADA_SUBCYCLES = 4 times inside every cycle of the fundamental, windowed per sub-cycle so none of the inner restarts click. BLOOM sweeps the ratio those four sub-cycles carry; the pitch never moves. Four is a chosen density, not a derived one — this is where a different number would announce itself.

D

RATCHET's ladder

Do the steps read as a dial being turned, or a warble?

RATCHET holds each rung for RATCHET_STEP_SECONDS = 0.15s and only steps at the next phase wrap — never a glide between harmonics. DECAY 0.9 gives the note room for several steps. Each clip's ladder below is the exact array Glint.ratchetLadder computed for it, printed to the generator's own console when this set renders — the rung counts here are that same record, not a separate guess.

E

PLATE's fall

Does the brightness really track the note's own loudness?

PLATE has no clock of its own: k(t) = kBase · (1 + BLOOM · amp_env(t)) ties the formant directly to the amplitude envelope. The point of this section is the cross-comparison: the DECAY 0.95 pair should still sound brighter than the DECAY 0.3 pair at the same instant into the note, because the fall follows each note's own decay rather than a fixed rate.

F

The dissent

Is RATCHET's bleep a defect, or a lineage?

The spec records a designer's argument that GLINT's toy-like "bleep" character is a lineage worth keeping rather than a flaw to engineer away, and that RATCHET — stepping between fixed harmonics like an old chip tune — is that position given a voice. Three PEAK settings, everything else at RATCHET's defaults. If this is the one you reach for, the roadmap should follow it.
