A new kick and snare built from interacting drumheads, shell modes and snare-wire contacts. Start with the same bare kick/snare phrase in all three versions, then isolate each drum.

170 BPM · 2 voices · 3 velocities × 3 physical strikes

Matching changes each whole clip’s gain, preserving its internal dynamics. The new synthesis clips contain no recordings. Acoustic references are labeled separately.
