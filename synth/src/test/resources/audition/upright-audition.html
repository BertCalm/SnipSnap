Inside the voice

The gesture is finger release → string ring → wooden response → damped tail. A released initial-displacement profile excites a tuned lossy string. The body is a one-way filtered readout. No finger collision, bowing, slap, bridge backreaction or measured upright realism is claimed.

These are finite notes. There is no HOLD loop, sustained keygroup or note-off-release claim. Recipes retain TUNE, TOUCH, DAMP, WOOD and source playing strength. Phrase recipes describe a finite audition performance with one production recipe per event.

Why it is built this way

One string keeps the note clear. The body responds to the same played string. Playing strength changes excitation as well as level. Muting supplies useful short notes alongside the round decay.
